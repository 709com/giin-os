# 「文京区まとめ」を政務活動費で運営する際の留意点（確認日 2026-11-07）

調査担当（AI）の報告をそのまま保存。**法的助言ではなく実務上の留意点の整理**。断定できない点は「要確認」。最終判断は文京区議会事務局（庶務係 03-5803-1312）と選挙管理委員会への照会で固める。

## 1. 他自治体の支出事例

- SNSの運用費や従量課金のAPI費用を使途基準にはっきり書いている23区の例は見つからなかった（要確認）。多くの議会はホームページの作成・維持の経費を「広報費」に入れており、SNSも同じ枠とみられる。
- **板橋区**：広報費の例に「ホームページ作成・更新（管理）」（上限100%）。私的・政党・選挙・後援会活動が混ざらないことが条件で、混ざるときは2分の1まで。任期満了前（3か月前程度）の広報は特に注意。インターネット経費は別枠で50%が上限。
- **さいたま市**：政務活動目的のホームページは計上できるが、政党・後援会の記述や議員の経歴があるときは掲載面積の割合などで按分。他会派の一般質問や議案を載せてもよい。
- **杉並区**：区議選・区長選のおおむね3か月前の区政報告は按分割合を慎重に扱う。
- **当てはめ（要確認）**：X APIとXプレミアムは「広報費」、Claude APIは「広報費」か「資料作成費」が自然。項目と全額充当の可否は事前に事務局へ確認。

## 2. 問題になった事例

- **尼崎市（神戸地裁、2022年9月27日判決）**：会派ホームページの議員写真・プロフィール部分（画面の約12%）は政務活動と合理的関連性が否定され、面積分（約1万6千円）の返還命令。
- **さいたま市（住民監査請求、2025年）**：ホームページ費を按分しなかったことが争われ棄却。ただし政党の肩書部分（130円）は議員が自主返納。監査委員は按分の徹底を意見。
- **奈良県（監査）**：ホームページ維持費100%充当で、2分の1を目的外支出と判断。山形県の監査も同様の類型。
- **堺市（2024年）**：「市政報告」と書いた選挙色の強いチラシに返還を求める住民監査請求。
- **共通点**：返還につながるのは「議員個人の宣伝」「政党の情報」「選挙色」。全議員を同じ形で扱い、顔写真・プロフィール・政党の肩書を出さない運営はこの争点を避ける方向。

## 3. 公選法上の留意点

- **選挙運動**：特定の選挙で、特定の候補者の当選（落選）を目的に、投票を得るため有利な行為をすること。当たらない政治活動は別扱い。
- **事前運動の禁止**：選挙運動ができるのは立候補届の受理から投票日の前日まで（129条、罰則239条）。
- **ネット選挙**：2013年改正でウェブ・SNSの選挙運動は解禁。選挙運動用の電子メールは候補者・政党のみ。ネットの内容を印刷して配るのは禁止（243条）。投票日当日はネットでも選挙運動のための更新ができないと一般に解説されている（条文原文は要確認）。
- **選挙後のあいさつ**：当選・落選のお礼の文書図画は制限（178条）。ネットも含むとする選管の見解の報道あり。
- **方針の妥当性（実務的所見）**：「選挙には触れない」「全議員を同じ形で扱う」は妥当な方向。加えて：
  - 告示前のおおむね3か月と、告示日から投票日までは、区の公式情報だけにするか止めることを検討。
  - 会派の議員だけが目立つ取り上げ方（回数・順番・写真）をしない。
  - 投票の呼びかけ、立候補予定者の紹介、当選・落選への言及をしない。
  - 政務活動費は選挙に係る費用には一切使えない（文京区の基準）。期間中の費用の扱いは事務局に確認（要確認）。

## 4. 文京区議会の基準

- **条例 別表第一**：広報費は「会派が行う活動、区政について住民に報告するために要する経費」。
- **「政務活動費の使用に係る留意事項」（令和5年3月13日改正）**：広報費の1番目に「選挙に係る費用には一切使用することができない」。政党・政治団体のニュースの発行には使えない。「ホームページの作成、維持管理等の経費に使用することができる」。インターネット接続料は控室の回線なら全額、それ以外は2分の1まで。**SNSやAPIの記述はない（要確認）**。
- **報告マニュアル（令和5年5月版）**：合理的に分けられないときは1/2を按分の基準。政党・選挙・後援会活動の経費には使えない。

## 5. 証拠書類

文京区のマニュアルで求められていること：
- 領収書には宛名（会派名）・日付・金額・内訳・発行者。X社・Anthropic社の請求先名義は会派名にしておくのが安全。
- クレジットカード払いは、カード利用代金明細書（政務活動費分以外は黒塗り）と請求書など内容が分かる書類。Web上だけの明細は印刷して添付。
- カードのポイントが確認できない場合は一律2.0%を差し引いて計上。政務活動費専用カードの使用を推奨。
- 任期をまたぐ後払いは4月30日までに支払う。
- ドル建て請求の円換算の記述はマニュアルにない（要確認）。カード明細の円の確定額で計上するのが実務的。

あわせて保管を勧めるもの：
- X APIの使用量明細（投稿数、URL付き投稿の数）
- 台帳から出した月ごとの投稿一覧（URL・日時・本文）
- Claude APIの使用量明細。**議員OSの他の装置とAPIキーを分け**、まとめ用の費用だけが分かるようにする
- Xプレミアムの請求書
- 運営方針（選挙に触れない・全議員を同じ形で扱う）を書いた文書
