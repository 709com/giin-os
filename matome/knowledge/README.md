## 今の運用に関わる要点（2026-11-07時点、秘書のまとめ）

- 「親はリンクなし＋返信にリンク」は、Xの公式見解（リンクで不利にしていない）と、外部の計測（一般アカウントのリンク投稿は反応が弱い）が食い違っている。**仮説として続け、数週間ずつ比べて決める**のがよい。
- 他の議会の公式Xは「日程・中継・結果を淡々と流し、返信しない」型がほとんど。一般質問の質問者・順番・項目を事前に流す例（佐久市議会）は、文京区まとめの型1のスレッドと同じ考え方。
- 避けるべきは、会派の意見や評価を混ぜること、区の検討中の案を先に出すこと、投稿しっぱなしで反応を見ないこと。
- 返信は表示の点数がとても重い（2023年公開の仕組み）。区民からの返信にどう応えるかは、会派の運用方針として先生が決める事項。
- Xプレミアムは表示が約10倍というデータがある（加入は決定済み）。
- 政務活動費：文京区の基準に「SNS・API」の明記はない。広報費として計上できるか、全額充当でよいかは**区議会事務局への事前確認が必要**（要確認）。請求先名義は会派名に、Claude APIのキーは議員OSの他装置と分けるのが安全。
- 公選法：告示前おおむね3か月と選挙期間中は、区の公式情報だけにするか止めることを検討。投票日当日の扱いは選挙管理委員会に確認。
